# Deuxième audit : corrections (2026-09-27) — Guide de test

Ce qui a changé et comment le vérifier. Les tests automatiques couvrent chaque point (`make test`, `make e2e-client`, `make e2e-web`) ; ce guide sert aux essais à la main, surtout sur **Windows**.

## 1. Tes trois demandes
- **Saisie après suppression d'un salon** (Windows) : roue dentée d'un salon › Supprimer → une fenêtre **de l'application** demande confirmation (plus la boîte grise de Windows). Confirmer, cliquer sur un autre salon, écrire : ça doit marcher du premier coup. Même chose pour : retirer un ami, bloquer, quitter un groupe, supprimer un rôle ou un bot, expulser, transférer la propriété.
- **Fils** : survol d'un fil dans la liste des salons → roue dentée (renommer, supprimer) ; clic droit sur le fil → « Renommer le fil », « Supprimer le fil… » ; roue dentée dans l'en-tête d'un fil ouvert ; dans un forum, clic droit sur un post. Supprimer le fil ouvert ramène à son salon.
- **Inviter un ami** : menu du serveur › « Inviter des personnes » → tes amis sont listés → « Inviter ». L'ami reçoit un message privé avec une **carte** « Invitation sur un serveur » → « Rejoindre ». Chez toi, la même carte affiche « Ouvrir ». Un ami déjà membre est marqué « Déjà membre ».
- Un second serveur **auto-signé** à la **même adresse** qu'un serveur déjà rejoint : refus avec l'explication « Quarel n'en suit qu'un par adresse » ; le premier serveur continue de marcher (avant, il était coupé).

## 2. Clés d'accès
- Connexion avec « Utiliser une clé d'accès » : la page du navigateur indique **l'appareil, l'adresse IP et l'heure**, avec un avertissement. Après la clé, elle affiche un **code à 6 chiffres** ; l'application demande « Code affiché par la page ». Un mauvais code est refusé (5 essais).
- Ajouter une clé → email « clé d'accès ajoutée ». Retirer une clé demande le mot de passe → email « clé d'accès retirée ».

## 3. Serveurs communautaires
- **Webhooks** : un rôle a désormais « Gérer les webhooks » (les rôles qui géraient les salons l'ont reçu à la mise à jour). Sans le droit d'écrire dans un salon d'annonces, impossible d'y créer un webhook.
- **Fils archivés** : un fil sans message pendant 7 jours disparaît de la liste (difficile à tester à la main : couvert par les tests) ; le lien « Ouvrir le fil » sous son message l'ouvre avec le bandeau « Fil archivé… » ; écrire le fait revenir. Créer plus de 5 fils ou posts en 10 minutes (sans gérer le salon) est refusé.
- **Modération automatique** : avec un mot interdit, essayer de le glisser avec une lettre cyrillique (« с » au lieu de « c ») : refusé. Un surnom ou un nom de fil avec le mot : refusé aussi.

## 4. Vie privée
- Paramètres › Voix et vidéo › **« Qui peut voir mon adresse IP »** : « Mes amis seulement » par défaut. Dans un appel de groupe avec quelqu'un qui n'est **pas** ton ami, sa tuile indique « relais » (si ton service d'identité a un relais) ; avec un ami, « en direct ».
- **Messages éphémères** : leurs notifications disent seulement « Nouveau message éphémère ». Une phrase de récupération restaurée sur un nouvel appareil ne les contient pas.
- `||divulgâcheur||` : caché dans les notifications (▒▒▒▒) ; un lien caché n'a pas d'aperçu.
- **Mes données** : Paramètres › Confidentialité › « Télécharger mes données » → un fichier JSON (compte, appareils, amis, conversations, et l'historique des messages privés de l'appareil). Menu d'un serveur › « Mes données sur ce serveur » → tes messages sur ce serveur.
- **Compte supprimé** : ses messages restent sur les serveurs, sous le nom « Ancien compte » (dans les 10 minutes). S'il possédait le serveur, un nouveau code de revendication apparaît dans le journal / la page d'administration.

## 5. À savoir
- Mettre à jour **serveurs et service d'identité avant l'application**.
- Ici, sous Linux, la capture d'écran des tests d'appels échoue parfois (limite de l'écran virtuel, déjà vraie avant ces changements).
