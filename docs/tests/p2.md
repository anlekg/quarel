# P2 — Guide de test

> Tests automatiques : `make test` (Go), `make e2e-client` (application et version web), `make e2e-dm-groups`, `make e2e-moderation`.
> Ces fonctions arrivent avec la **0.4.0** (application de bureau, serveurs et service d'identité). Plusieurs demandent que **les deux personnes** aient la 0.4.0.

## Appels entre amis
1. **Partage d'écran** : pendant un appel entre deux applications 0.4.0, bouton « écran » de la barre d'appel → choix de l'écran ou de la fenêtre. L'autre personne le voit au-dessus des tuiles. Les deux peuvent partager en même temps.
   - **Sous Windows, avec le son du système** : vérifiez que votre ami·e **n'entend pas sa propre voix** en retour (ce point n'a pas pu être testé sous Wine).
2. **Appels de groupe** (6 personnes au plus) : dans un groupe de messages privés, bouton « téléphone » → les autres reçoivent une sonnerie (« Rejoindre » / « Ignorer »). Tant que l'appel dure, le groupe affiche « Rejoindre l'appel (n) » : on peut partir et revenir. Caméra et partage d'écran marchent comme à deux.

## Messages privés
3. **Messages éphémères** : horloge en haut d'une conversation → 5 minutes (le plus court pour tester). Le changement s'affiche dans la conversation chez tout le monde ; les messages suivants portent une petite horloge et disparaissent 5 minutes après leur envoi, sur tous les appareils (fichiers compris). Remettez « Désactivés » ensuite.
4. **Qui peut me demander en ami** : Paramètres › Confidentialité → « Personne » : une demande d'ami de quelqu'un d'autre est refusée (« n'accepte pas de demande d'ami de votre part »). Une demande que **vous** avez envoyée reste acceptable.

## Serveurs communautaires (Paramètres du serveur)
5. **Modération automatique** : ajoutez un mot interdit (`arnaq*` par exemple), cochez « Refuser les liens ». Avec un compte sans droit de modération, envoyez « une arnaque » ou un lien : refusé, avec la raison. Trois refus en 10 minutes → exclusion automatique (si réglée). Le journal de modération note chaque refus, sans le texte.
6. **Emojis** : section « Emojis » → ajoutez une petite image PNG. Dans un salon, tapez `:` puis le début du nom (Tab) ; utilisez-le aussi en réaction.
7. **Webhooks** : roue dentée d'un salon › Webhooks › créez-en un, copiez l'adresse, puis dans un terminal :
   `curl -X POST -H 'Content-Type: application/json' -d '{"content":"Bonjour du webhook"}' <adresse>` → le message apparaît, marqué WEBHOOK.
8. **Commandes slash** : avec le bot d'exemple (`examples/pingbot`, voir le wiki « Écrire un bot »), tapez `/` dans un salon : `/ping` (réponse visible par tout le monde, « X a utilisé /ping ») et `/echo bonjour` (réponse visible par vous seul·e).
9. **Forums** : « Créer un salon » › type Forum → « Nouveau post » (titre + message). Les posts les plus actifs remontent en tête ; on répond dans un post comme dans un fil.
10. **Scènes** : réglages d'un salon vocal › cochez « Scène ». En arrivant, on est dans le **public** (micro grisé) ; « Lever la main » ; la modération voit la main levée et « Inviter à parler ». « Quitter la scène » ramène dans le public.
11. **Mise en forme** : dans un message, essayez `# Titre`, `- liste`, `> citation`, `~~barré~~`, `__souligné__`, `||divulgâcheur||` (cliquez pour le révéler), un bloc de code avec ` ```js `.

## Compte
12. **Clé d'accès** (double authentification activée) : Paramètres › Sécurité › Clés d'accès › « Ajouter une clé » → une page de votre service d'identité s'ouvre dans le navigateur : utilisez Windows Hello, une clé USB ou votre téléphone. Déconnectez-vous puis, à l'étape du code, « Utiliser une clé d'accès » : validez dans le navigateur, l'application se connecte seule.

## Version web sur téléphone
13. **Notifications même fermée** : sur le téléphone, installez l'application web (menu du navigateur › « Installer » / « Ajouter à l'écran d'accueil »), puis Paramètres › Notifications › « Même quand l'application est fermée ». Fermez-la et faites-vous envoyer un message privé : une notification « Du nouveau vous attend » arrive (sans contenu : c'est voulu). Un clic ouvre Quarel.

## Confort de l'application de bureau
14. **Mise à jour invisible** (visible à partir de la mise à jour **suivant** la 0.4.0, car c'est l'application installée qui lance l'installation) : quand le bandeau « Mise à jour prête » apparaît, « Redémarrer » ferme Quarel, installe **sans fenêtre** puis le rouvre.
15. **Zone de notification** (Windows) : la croix cache Quarel près de l'horloge ; un message privé arrive quand même (notification) ; clic sur l'icône → la fenêtre revient ; clic droit sur l'icône › « Quitter Quarel » le ferme vraiment. Réglage : Paramètres › À propos.
16. **Ping** : barres de signal à gauche de « Vocal connecté » (survol : ms vers le serveur vocal), dans la barre d'appel et sur la tuile de chaque participant·e d'un appel.
17. **Clic droit** :
    - sur une personne dans le vocal ou la liste des membres : « Volume pour moi » (essayez 200 % : sa voix doit être nettement plus forte, **sans grésillement**) et « Rendre muet pour moi » ; avec des droits : couper son micro, l'exclure 10 minutes (puis « Lever l'exclusion »), l'expulser ;
    - sur un message : réactions rapides, répondre, copier, épingler, supprimer ;
    - sur un salon : marquer comme lu, modifier ;
    - sur une tuile d'appel : volume de la personne.

## À savoir
- Le partage d'écran d'un appel et les appels de groupe ne marchent qu'entre applications 0.4.0 : face à une 0.3.0, le bouton n'apparaît pas.
- Les notifications de mentions sur les serveurs ne passent pas encore par ce réveil (seulement les messages privés et les appels).
